# arXiv Submission Checklist

## Before Upload

- confirm you can submit to `cs.AI`
- if this is your first submission in the category, confirm endorsement status
- decide whether to cross-list to `cs.CL`
- confirm you want the paper under `CC BY 4.0`

Reference pages:

- endorsement: `https://info.arxiv.org/help/endorsement.html`
- metadata prep: `https://info.arxiv.org/help/prep.html`
- license help: `https://arxiv.org/help/license`
- TeX environment: `https://info.arxiv.org/help/faq/texlive.html`

## Upload Bundle

Use:

- `docs/article-plans/arxiv-submission/live-agent-risk-arxiv-source.tar.gz`

or upload the contents of:

- `docs/article-plans/arxiv-submission/live-agent-risk-arxiv-source/`

## Submission Settings

- compiler: `pdflatex`
- source submission: `LaTeX`
- primary category: `cs.AI`
- cross-list: `cs.CL`

## Metadata Entry

- use the title exactly as drafted
- use the plain-text abstract from `metadata_draft.md`
- use the comments field from `metadata_draft.md`
- leave journal reference and DOI blank for now

## After arXiv Compiles

- inspect the generated PDF page by page
- check that all 7 figures are present
- check citations and references
- check line breaks in the appendix artifact table
- check that the title and abstract were rendered correctly

## Final Check

- verify the arXiv preview matches the local PDF closely
- verify author name spelling
- verify category is correct
- verify license selection before finalizing
